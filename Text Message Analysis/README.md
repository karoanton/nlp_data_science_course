# Text Message Analysis Portfolio Project

This portfolio project was completed as part of the requirements for the Codecademy.com Data Scientist - Natural Language Processing carreer path course.

## Database:
<b> The National University of Singapore SMS Corpus dataset </b>

Tao Chen and Min-Yen Kan (2013). Creating a Live, Public Short Message Service Corpus: The NUS SMS Corpus. Language Resources and Evaluation, 47(2)(2013), pages 299-355. URL: [https://link.springer.com/article/10.1007%2Fs10579-012-9197-9]

## Libraries Used:
- Pandas
- Numpy
